# How to connect the machine

1、Before connecting the machines, first provide a list of the machines to connect.

2、After confirming the machines that need to be connected, we can't connect them after payment.

3、Before connecting the machine, please provide the processing data for the device. The detailed data requirements are as follows.

- Package the current device's data into a zip file named after the device
- If the current device is a CNC cutting machine, and double-sided flipping processing is needed, then he needs to provide the machining files for both sides.
- If the current device's data is as complete as possible, don't just provide a single file
- If it's a six-face drilling machine, then tell us what format of data to use
- If the connected device is an electronic saw cutting machine, provide a CSV file or processing data.

4、After the data is provided, our technicians will do post-processing configuration on it. Once the configuration is done, we’ll do remote setup in the after-sales group.

5、When we're doing the data integration setup remotely, please cooperate with testing the equipment and give feedback on any issues promptly.

6、Once the device tests work properly, it means the integration work is done.
